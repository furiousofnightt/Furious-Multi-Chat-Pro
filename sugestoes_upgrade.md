# 🚀 Sugestões de Melhorias e Upgrades Futuros

Este documento contém ideias para tornar o **Furious Multi Chat Pro** ainda mais robusto, profissional e útil para streamers, mantendo o foco na simplicidade e facilidade de uso com o OBS.

---

### 1. 🎨 Personalização Visual (Temas e Fontes) - [CONCLUÍDO] ✅
Para um app que fica sobreposto ao jogo, a estética é tudo.
- **Modo Glassmorphism**: Adicionar uma opção de desfoque (blur) no fundo da janela para um visual Windows 11 moderno.
- **Seleção de Fontes**: Permitir que o usuário escolha entre 3 ou 4 fontes populares (Inter, Roboto, Montserrat).
- **Cores por Plataforma**: Permitir que o usuário escolha a cor de destaque de cada chat (ex: mudar o roxo da Twitch por outra cor).

### 2. 🛡️ Moderação Básica (Filtro de Palavras) - [CONCLUÍDO] ✅
Ajudar o streamer a manter a live limpa sem esforço.
- **Blacklist de Palavras Profissional**: Sistema de tags com 'x' para gerenciar palavras bloqueadas. Já implementamos o filtro e a interface!

### 3. 🔄 Resiliência de Conexão (Auto-Reconnect) - [CONCLUÍDO] ✅
Evita que o streamer precise reabrir o app se a internet oscilar.
- **Reconexão Inteligente**: Se uma plataforma cair, o app tenta reconectar sozinho a cada 30 segundos, sem exibir erros técnicos chatos, apenas uma pequena mensagem de "Tentando reconectar...".

### 4. ⌨️ Atalhos de Teclado (Hotkeys) - [CONCLUÍDO] ✅
Agilidade durante a gameplay.
- **Global Hotkeys**: Atalhos (ex: `Ctrl + Shift + C`) para limpar o chat ou `Ctrl + Shift + H` para esconder/mostrar a janela rapidamente ou entao permitir que o usuario configure os atalhos, ttambem permitir que o usuario configure tecla de atalho para mostrar ou esconder o chat na tela fazendo o chat continuar ativo no ray tipo se clicar na tecla de atalho o chat aparece e se clicar novamente ele some mas continua ativo no ray.

### 5. 📥 Melhoria na Experiência do Usuário (QoL) - [CONCLUÍDO] ✅
- **Minimizar para a Bandeja (System Tray)**: Ao fechar ou minimizar, o app vai para perto do relógio do Windows, liberando espaço na barra de tarefas.
- **Botão Minimizar no Header**: Adicionado botão dedicado para minimizar rápido.
- **Log de Erros Amigável**: Se algo falhar, mostramos mensagens amigáveis como "Live offline ou canal não encontrado".
- **Design Clean**: Emojis genéricos foram substituídos por Ícones SVG profissionais e LEDs de status dinâmicos.
- **Controle de Marcha Lenta**: O streamer agora tem um controle de atraso de mensagens para ler o chat tranquilamente na velocidade que quiser.
- **Fix UI (Word Wrap)**: Mensagens longas com quebra de linha não são mais cortadas, ajustando-se nativamente à altura.


### 6. 🖼️ Suporte a Imagens e Gifs (Emotes) - [CONCLUÍDO] ✅
Expandir o que já temos.
- **Suporte a 7TV/BTTV**: Adicionar suporte automático para os emotes mais famosos da Twitch que não são os oficiais.
- **Badges de Moderator/VIP**: Mostrar o ícone de moderador ou VIP ao lado do nome do usuário.
